## Live website

After enabling GitHub Pages, the site should be available at:

`https://Siddharth2006x.github.io/`

## Features

- Responsive layout for desktop, tablet and mobile
- Dark blue, purple and cyan visual identity
- About, skills, projects, creative work and contact sections
- Mobile navigation menu
- Basic SEO metadata and social sharing metadata
- No build tools or framework required

## Publish with GitHub Pages

1. Create a public repository named exactly `Siddharth2006x.github.io`.
2. Upload all files and folders from this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to finish deploying.

## Personalise before publishing

- Replace the profile placeholder in `assets/profile.svg` with your own suitable portrait, or update the image path in `index.html`.
- Verify every skill and remove technologies you cannot confidently demonstrate.
- Update project titles, descriptions, technologies and repository links to match the real contents of your repositories.
- Add your own photography and video-editing images to the creative section.
- Add a professional email address or another contact method if you want visitors to contact you directly.

## SEO

The page includes a title, description, author, robots directive and Open Graph metadata. After deployment, add the site to [Google Search Console](https://search.google.com/search-console), verify ownership and request indexing. Indexing and ranking are controlled by Google and are not guaranteed.
